Once Bliss Browser exits the Pre-Alpha and Alpha stages, I don't expect it to gain marketshare very rapidly, due to 1 major factor: Bliss Browser supports freedom and ethics, and as such, opposes all forms of DRM. Because of this, almost every existing streaming service will likely be blocked, and any site that requires payment (paywall, or subscription) to use will also be blocked. I would rather keep my project ethical, than to be a contributor to the wrong cause.
